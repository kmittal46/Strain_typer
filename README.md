# 🧬 Strain-Typer

**Strain-Typer** is a modular Python pipeline for strain-level classification and benchmarking from pairwise genomic similarity results.

It processes genome–genome comparison outputs generated by tools such as **FastANI, Mash, and Skani**, integrates genome metadata and strain/substrain assignments, identifies the best genomic match for each query genome, evaluates classification accuracy, and generates summary visualizations.

---

## Features

- Supports pairwise genome comparison outputs from:
  - FastANI
  - Mash
  - Skani
  - Sourmash
  - Custom tabular comparison tools
- Converts different score types into a common similarity scale
- Supports ANI, similarity, and distance scores
- Automatically detects common input columns
- Integrates genome-to-strain metadata
- Identifies the top genomic match for each query
- Calculates overall top-hit classification accuracy
- Calculates accuracy for individual strain clusters
- Generates per-cluster accuracy plots
- Generates cluster-to-cluster similarity heatmaps
- Produces a detailed output table and run summary
- Creates a separate output directory for each analysis

---

## Workflow

Strain-Typer is designed as a post-processing and benchmarking layer:

Genome comparison tool
↓
Pairwise similarity results
↓
Strain-Typer
↓
Metadata integration
↓
Top-hit classification
↓
Accuracy evaluation
↓
Visualizations + summary

The comparison algorithms themselves are performed by external tools such as FastANI, Mash, or Skani. Strain-Typer processes and evaluates their results.
